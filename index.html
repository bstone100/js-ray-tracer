My first ray tracer

This is my first attempt to write a ray tracer. It's inspired by the book Ray Tracing in One Weekend by Peter Shirley and the book Computer Graphics from Scratch by Gabriel Gambetta.

The first version is going to be just rendering some spheres in a <canvas> element.

Front view

In this view the camera is in front of all the objects, staring down the +Z axis, so we're seeing the YX plane.

Right view

In this view the camera is to the right of all the objects, staring down the -X axis, so we're seeing the YZ plane.

Top-down view

In this view the camera is above all the objects, looking down upon them, staring down the -Y axis, so we're seeing the ZX plane.
